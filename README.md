# Data Analyst Portfolio — Real Sales Datasets

## What this is

Two real-world sales datasets downloaded from the internet for practicing data cleaning, analysis, and dashboard building in Excel.

## Datasets

| File | Source | Rows | Description |
|------|--------|------|-------------|
| `data/superstore_sales.csv` | GitHub (Superstore Sales Analysis) | ~5,900 | US retail sales: orders, products, regions, profits, returns, payment modes |
| `data/ecommerce_sales.csv` | GitHub (E-Commerce Sales Analysis) | ~5,000 | Indian e-commerce: customer names, categories, discounts, profits, payment methods |

## How to use

1. Open either file in Excel
2. Look for data quality issues: `#N/A` values, mixed date formats, inconsistent naming
3. Clean the data using Excel formulas
4. Build pivot tables and charts
5. Create a dashboard
