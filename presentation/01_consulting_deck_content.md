## SLIDE 13: Appendix — Data Cleaning Log

| Issue | Resolution |
|-------|-----------|
| Mixed date formats (DD/MM/YYYY, YYYY-MM-DD, DD-Mon-YY) | Standardized to ISO 8601 |
| Missing quantity (Order 1003) | Filled as 0, flagged |
| Inconsistent product naming ("Coke" vs "Coca Cola") | Normalized to master list |
| Currency appended to values ("JD", "JOD") | Removed, converted to numeric |
| Inconsistent case in regions | Standardized to Title Case |
| Duplicate row (Order 1001, 2049) | Removed, kept first occurrence |
| Negative quantity (Order 2060, return) | Kept as separate return record |
